1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие персональные данные собирает мобильное приложение KiteSense (далее — «Приложение»), как они используются, хранятся и защищаются.

Политика составлена в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Используя Приложение, вы соглашаетесь с условиями настоящей Политики. Если вы не согласны с ней — пожалуйста, не используйте Приложение.

2. Какие данные мы собираем

2.1. Данные, предоставляемые вами

  • Email — при регистрации для создания аккаунта.
  • Имя пользователя (username) — отображается друзьям и другим пользователям.
  • Вес — для расчёта рекомендаций по снаряжению.
  • Уровень владения кайтом — для персонализации рекомендаций.
  • Физическая форма — для персонализации рекомендаций.
  • Снаряжение (кайты, доска) — для подбора рекомендаций.
  • Фотографии профиля (аватар) — по желанию.

2.2. Данные, собираемые автоматически

  • Геолокация — для отображения вашего положения на карте спотов, подбора ближайших спотов и функции присутствия на спотах. Данные о местоположении используются только во время работы Приложения и не передаются третьим лицам, кроме случаев, описанных в разделе 4.
  • Данные о сессиях — треки (координаты маршрута), скорость, дистанция, длительность. Используются для ведения журнала и статистики.
  • Техническая информация — тип устройства, версия ОС, идентификаторы для отладки и обеспечения работы Приложения.

2.3. Данные, загружаемые вами в сервис школ

  • Фотографии инструкторов и школ — при размещении карточек кайт-школ (для владельцев школ).
  • Контактные данные школ — телефон, WhatsApp, email, сайт, Instagram, Telegram (для владельцев школ).

2.4. Социальные функции

  • Список друзей — добавление друзей и просмотр их присутствия на спотах.
  • Присутствие на спотах — отображается только вашим друзьям (если включена функция).

3. Как мы используем ваши данные

  • Для создания и управления аккаунтом.
  • Для расчёта персональных рекомендаций по снаряжению и одежде на основе погоды, вашего веса, уровня и физической формы.
  • Для отображения вашего положения на карте и подбора ближайших спотов.
  • Для ведения журнала сессий (треки, статистика).
  • Для социальных функций (друзья, присутствие на спотах).
  • Для обеспечения безопасности и предотвращения злоупотреблений.

4. Передача данных третьим лицам

Мы не продаём и не передаём ваши персональные данные в маркетинговых целях. Данные могут передаваться следующим сервисам для обеспечения работы Приложения:

  • Supabase (хостинг базы данных и авторизации). Ваши данные хранятся на серверах Supabase. Подробнее: supabase.com/privacy.
  • OpenWeatherMap и Open-Meteo — получение погодных данных. Персональные данные не передаются, используются только координаты спота.
  • Resend — отправка служебных email (подтверждение регистрации, сброс пароля). Персональные данные не передаются, кроме адреса получателя.
  • DeepSeek — сервис AI-рекомендаций (планируется в будущих версиях). При подключении функции в Политику будут внесены соответствующие изменения.

Передача данных третьим лицам осуществляется только в объёме, необходимом для работы Приложения, и в соответствии с политиками конфиденциальности соответствующих сервисов.

5. Хранение и защита данных

  • Данные хранятся на серверах Supabase с использованием шифрования при передаче (HTTPS/TLS).
  • Доступ к базе данных ограничен ролевой моделью (RLS — Row Level Security).
  • Пароли хранятся в виде хешей, мы не имеем доступа к вашим паролям в открытом виде.
  • Срок хранения данных — до удаления вашего аккаунта.

6. Ваши права

Вы имеете право:

  • Получить информацию о том, какие ваши данные мы обрабатываем.
  • Исправить свои данные — через редактирование профиля в Приложении.
  • Удалить аккаунт и все связанные данные — через настройки Приложения («Удалить аккаунт»). Удаление происходит безвозвратно.
  • Отозвать согласие на обработку персональных данных — путём удаления аккаунта или письменного обращения на support@kitesense.ru.

7. Файлы cookie и аналитика

Мобильное приложение KiteSense не использует файлы cookie для отслеживания. Технические данные (тип устройства, версия ОС) собираются исключительно для отладки и обеспечения стабильной работы.

8. Дети

Приложение не предназначено для лиц младше 12 лет. Мы не собираем данные детей младше 12 лет сознательно. Если вам стало известно, что ребёнок младше 12 лет предоставил нам свои данные, свяжитесь с нами — мы удалим их.

9. Изменения в Политике

Мы можем обновлять настоящую Политику. Актуальная версия всегда доступна по адресу kitesense.ru/privacy.html. При существенных изменениях мы уведомим вас через Приложение.
